## 3. GOOGLE SEARCH CONSOLE SETUP

### Steps:
1. Go to search.google.com/search-console
2. Add property → Domain type → enter `divyotsav.com`
3. Verify via DNS TXT record (add to domain registrar)
4. Once verified, submit sitemap:
   ```
   https://divyotsav.com/sitemap.xml
   ```

### Generate sitemap automatically:
Install `next-sitemap`:
```bash
npm install next-sitemap
```
Create `next-sitemap.config.js`:
```javascript
module.exports = {
  siteUrl: 'https://divyotsav.com',
  generateRobotsTxt: true,
  changefreq: 'weekly',
  priority: 0.8,
  exclude: ['/studio/*']
}
```
Add to `package.json` scripts:
```json
"postbuild": "next-sitemap"
```
This auto-generates `sitemap.xml` and `robots.txt` on every build.
